# Watcher домашних заданий ProductStar

Скрипт каждые N секунд проверяет твой личный кабинет и присылает в Telegram
уведомление, как только появляется новое домашнее задание. Реагируешь первым.

## Что нужно сделать один раз (≈10 минут)

### Шаг 1. Установить зависимость
Открой PowerShell в этой папке и выполни:
```powershell
pip install requests
```

### Шаг 2. Поймать запрос из браузера
Скрипту нужно обращаться к сайту от твоего имени. Забираем «слепок» запроса:

1. Открой в Chrome страницу https://hr.productstar.ru/homeworks (залогинься).
2. Нажми **F12** → вкладка **Network** (Сеть).
3. В фильтре вверху нажми **Fetch/XHR**.
4. **Обнови страницу** (F5). В списке появятся запросы.
5. Найди запрос, в ответе которого есть список домашек (обычно называется
   `homeworks`, `tasks`, `list` и т.п. — кликай по ним и смотри вкладку
   **Response**, там должен быть JSON со списком заданий).
   - Если не найдёшь такой запрос — не страшно, возьми самый первый запрос
     документа (тип `document`) на `hr.productstar.ru/homeworks`.
6. **Правой кнопкой** по нужному запросу → **Copy** → **Copy as cURL (bash)**.
   ⚠️ Именно **bash**, не cmd/PowerShell.
7. Открой файл `request.curl` в этой папке, удали весь текст и **вставь**
   скопированное. Сохрани.

> Внутри этого запроса — твои куки авторизации. Файл никуда не отправляется,
> лежит только у тебя на диске. Раз в несколько недель авторизация может
> «слетать» — тогда просто повтори шаг 2 (скрипт предупредит в Telegram).

### Шаг 3. Создать Telegram-бота
1. В Telegram напиши боту **@BotFather** → команда `/newbot` → задай имя.
   Он выдаст **токен** вида `123456789:AAG...`. Вставь его в `config.json`
   в поле `telegram_token`.
2. Узнай свой **chat_id**: напиши что-нибудь своему новому боту (любое сообщение),
   потом открой в браузере ссылку (подставив токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найди в ответе `"chat":{"id":123456789` — это число вставь в `config.json`
   в поле `telegram_chat_id`.

### Шаг 4. Запуск
```powershell
python watcher.py
```
Первый запуск просто запомнит текущие задания. Как только появится новое —
придёт уведомление в Telegram. Останавливается по **Ctrl+C**.

## Уведомления «я жив»

Чтобы не гадать, работает watcher или молча упал:

- **При запуске** — сразу приходит сообщение: время старта по Москве,
  сколько заданий в памяти, во сколько ждать ежедневный отчёт.
- **Раз в сутки в 09:00 по Москве** — отчёт «жив-здоров»: время последней
  удачной проверки сайта и сколько он работает без перезапуска.
- **По запросу** — напиши боту `/ping` или `/status`, ответит тем же отчётом.

Команды (`/ping`, `/status`, `/cookie`) работают в том мессенджере, который
включён в `channels` — и в Telegram, и в МАКС. Бот отвечает туда же, откуда
пришла команда. Если включены оба канала, слушаются оба.

Настройки в `config.json` (обе необязательные, значения по умолчанию такие):
```json
"daily_report": true,
"daily_report_time": "09:00"
```
Время — всегда московское, независимо от часового пояса сервера.
`daily_report: false` выключает ежедневный отчёт (стартовое сообщение остаётся).

Если в 09:00 сервер был выключен, отчёт придёт при первой же возможности после
включения. Если watcher перезапустился днём — второго отчёта в тот же день не
будет, стартовое сообщение его заменяет.

## Частота проверок и ночной режим

Watcher проверяет сайт каждые `interval_seconds` секунд (по умолчанию 10,
меньше 5 поставить нельзя — защита от опечатки). Ночью сайт не трогает:
по умолчанию с 00:00 до 08:00 **по Иркутску**. Команды бота и ежедневный
отчёт ночью продолжают работать, а `/ping` честно скажет, что сейчас ночной режим.
Утром всё, что появилось за ночь и ещё висит на сайте, придёт уведомлениями сразу.

```json
"interval_seconds": 10,
"quiet_hours": "00:00-08:00"
```
`"quiet_hours": ""` — выключить ночной режим. Окно может переходить через
полночь, например `"23:30-07:00"`.

**Лёгкий запрос.** Вместо всей HTML-страницы (~45 КБ) watcher просит у сайта
только список домашек в JSON (~3 КБ) — штатным механизмом Inertia, которым
пользуется и сам сайт. Полная страница запрашивается только при старте и
когда сайт обновили (тогда приходит HTTP 409, это нормально). Если лёгкий
запрос трижды подряд не сработает, watcher сам вернётся к полной странице
до перезапуска — в логе будет «Лёгкий запрос отключён».

## Файлы
- `watcher.py` — сам скрипт
- `config.json` — токен, chat_id, интервал опроса, время ежедневного отчёта
- `request.curl` — запрос к сайту (твой, с куками)
- `seen.json` — какие задания уже видели (создаётся сам)
- `daily_report.txt` — дата последнего отчёта «жив-здоров» (создаётся сам)
- `last_response.txt` — последний ответ сайта (для отладки)
